# CODSOFT Java Programming Internship

This repository contains the tasks completed as part of my Java Programming Internship at CODSOFT.

## Task 1 – Number Guessing Game

### Description
A Java-based number guessing game where the computer randomly selects a number between 1 and 100, and the user tries to guess it within a limited number of attempts.

### Features
- Random number generation between 1 and 100
- User input using Scanner
- Too High / Too Low hints
- Maximum 7 attempts per round
- Score calculation based on attempts
- Multiple rounds supported
- Invalid input handling
- Final score display

### Technologies Used
- Java
- Java Scanner
- Java Random

### How the Game Works
1. The computer generates a random number between 1 and 100.
2. The player gets 7 attempts to guess the number.
3. The program provides hints after each guess.
4. If the correct number is guessed, the player receives a score.
5. The player can choose to play another round.
